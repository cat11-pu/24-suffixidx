# suffixidx

后缀数组倍增构造与相邻公共前缀查询工作台（原生 ES 模块，零依赖）：装载一份小写字母文本，按
倍增口径逐轮建出后缀数组、位次表与各轮快照，再算相邻公共前缀；定位事件给出两个后缀的公共前缀
长度。页面是后缀排名阶梯：一行一轮，格是按该轮顺序排的后缀起始下标，格底色是该轮的分组、角标
是位次，不变量直接印在行首与置顶状态条上。

## 起服务看页面

    python3 -m http.server 8000

浏览器打开 http://127.0.0.1:8000/ 即可装载与定位。

## 测试

    node tests/run.js

## 场景自检

    node check_sample.js
